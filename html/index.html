Tools

Empat halaman, masing-masing satu pekerjaan. Buka, pakai, tutup.

JSON

JSON Searcher

Paste object atau array, lalu cari dan filter hasilnya dalam tabel.

 Gaji

Perhitungan Lembur

Hitung upah lembur dari gaji, hari kerja, dan jam lembur.

 Hash

Hashids

Encode angka menjadi hash, atau decode hash menjadi angka.

 File

Boilerplate

Generate perintah dan file siap pakai, seperti Docker Compose Postgres dan Redis.

Cara pakai

Static files. Cukup folder html di belakang nginx.

Berjalan di browser

Logika ada di halaman itu sendiri. Data JSON Searcher disimpan di localStorage.

File biasa

HTML, CSS, dan JSON. Tidak ada build step untuk memakai tool-nya.

Port 8080

Mount folder html ke nginx. Buka localhost:8080 lalu pilih tool.
