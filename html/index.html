Tools

Empat halaman, masing-masing satu pekerjaan. Buka, pakai, tutup.

JSON

JSON Searcher

Paste object atau array, lalu cari dan filter hasilnya dalam tabel.

 Gaji

Perhitungan Lembur

Hitung upah lembur dari gaji, hari kerja, dan jam lembur.

 Hash

Hashids

Encode angka menjadi hash, atau decode hash menjadi angka.

 File

Boilerplate

Generate perintah dan file siap pakai, seperti Docker Compose Postgres dan Redis.

Cara pakai

Dari install sampai jalan. Pilih image Docker, clone repo, atau pasang sebagai aplikasi.

01 docker

Pull image lalu jalankan. Port 8080 di host mengarah ke nginx di dalam container. Buka http://localhost:8080. 

docker pull ghcr.io/cuytamvan/html-tools:latest
docker run --rm -p 8080:80 ghcr.io/cuytamvan/html-tools:latest

02 source

Ambil source dari github.com/cuytamvan/html-tools, build image sendiri, lalu run. 

git clone https://github.com/cuytamvan/html-tools.git
cd html-tools
docker build -t html-tools .
docker run --rm -p 8080:80 html-tools

03 pwa

Setelah halaman terbuka di browser (localhost atau HTTPS), HTML Tools bisa dipasang ke layar utama. Tidak perlu Docker lagi untuk pemakaian sehari-hari.

  1. Chrome / Edge. Di address bar, pilih ikon install, atau menu lalu Install HTML Tools.
  2. Safari di iPhone. Tombol Bagikan, lalu Add to Home Screen.
  3. Safari di Mac. File, lalu Add to Dock.
